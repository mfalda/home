Source code for a home page to be hosted in Github.

### How to install

0. install Ruby, for example in Windows you can use [RubyInstaller](https://github.com/oneclick/rubyinstaller2/releases/download/RubyInstaller-3.4.4-2/rubyinstaller-devkit-3.4.4-2-x64.exe);
1. clone the repository;
2. enter in the cloned directory;
3. install needed packages with `bundle install`;
4. start the dev webserver with `bundle exec jekyll serve --incremental`.
